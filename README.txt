# Deepak Rana — Independence Day Editorial Webpage

## Files
- `index.html` — Hindi article content and page structure
- `style.css` — complete visual theme/responsive design
- `script.js` — reading progress, dark/light theme and article index highlighting
- `assets/deepak-rana-logo.png` — supplied author icon/logo
- `assets/hero-flag-redfort.png` — hero image
- `assets/protest-students.png` — section image
- `assets/school-students.png` — education section image

## Image placement
1. `hero-flag-redfort.png` → top hero, right side.
2. `deepak-rana-logo.png` → header author logo, byline and footer author card.
3. `protest-students.png` → Section 01: स्वतंत्रता.
4. `school-students.png` → Section 03: शिक्षा.

Open `index.html` directly in a browser. No build tool is required.
